# Adicionar um usuário à organização

Antes de um usuário poder acessar o Brand Concierge, adicione-o à organização da Adobe Experience Platform no Adobe Admin Console.

## Pré-requisitos

* Você deve ter acesso de administrador à organização.
* O usuário deve estar disponível para adicionar individualmente ou por meio de um upload de usuário em massa.

## Adicionar um usuário

1. Vá para a **Admin Console**.
2. Selecione **Gerenciar** ou vá para **Usuários**.
3. Adicione usuários individualmente ou adicione vários usuários por meio de um upload em massa.
4. Se o usuário ainda não existir na organização, selecione a opção para adicioná-lo como um novo usuário quando solicitado.
5. Selecione o perfil de produto:

   * **Adobe Experience Platform**
   * O perfil de usuário padrão

6. Selecione **Salvar**.

O usuário recebe um convite por email confirmando o acesso à organização.

>[!IMPORTANT]
>
>O convite da organização fornece ao usuário acesso à organização, mas não concede acesso ao Brand Concierge. Para fornecer acesso ao Brand Concierge, crie e atribua uma função com a permissão Brand Concierge, conforme descrito em &quot;Criar uma função com permissão do Brand Concierge&quot; (LINK).

## Próximas etapas

Depois que o usuário for adicionado à organização, crie uma função com a permissão **Gerenciar Brand Concierge** e atribua o usuário a essa função.
