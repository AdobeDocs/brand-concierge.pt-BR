# Exportar conversas usando o Adobe CX Enterprise Coworker

Saiba como salvar e exportar conversas do Adobe Brand Concierge usando o Serviço de consulta do Adobe Experience Platform e o Adobe CX Enterprise Coworker. Este vídeo mostra como localizar nomes de tabelas de conjuntos de dados, solicitar dados de conversa para um intervalo de datas e baixar um CSV quando o Data Distiller estiver disponível em sua organização.

## Para quem é este vídeo?

* Desenvolvedores que precisam exportar dados de conversação do Brand Concierge

## Conteúdo de vídeo

* Localizar conjuntos de dados de conversa no Experience Platform e copiar seus nomes de tabela
* Solicitar ao Colaborador que recupere dados da tabela de respostas para um intervalo de datas especificado
* Entenda por que o Data Distiller é necessário para o download de CSV mostrado no vídeo
* Siga a política de tratamento de dados de sua organização ao armazenar exportações que podem conter informações de identificação pessoal (PII)

>[!VIDEO](https://video.tv.adobe.com/v/3504550?captions=por_br)

>[!NOTE]
>
> Se o Data Distiller não estiver disponível em sua organização, o Colaborador não poderá criar o download do CSV mostrado neste vídeo. Selecione [Assistir ao Serviço de Consulta e ao vídeo do Terminal](exporting-conversations-using-query-service-and-terminal.md) para saber como exportar dados da conversa para um arquivo CSV usando Terminal.

Para obter a documentação, consulte a [ajuda do Brand Concierge](../documentation/overview.md).
