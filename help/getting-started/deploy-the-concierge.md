# Implantar o concierge

A implantação do Adobe Brand Concierge o disponibiliza para visitantes reais do site. Este vídeo descreve como configurar um fluxo de dados para rastrear o envolvimento do visitante e, em seguida, definir a configuração da superfície para controlar em quais páginas e domínios o concierge aparece.

## Para quem é este vídeo?

* Profissionais de marketing implantando um concierge em seu site
* Equipes de TI ou de desenvolvimento da Web que fornecem uma ID de sequência de dados e instalam o script
* Equipes que controlam onde o porteiro aparece em todo o site

## Conteúdo de vídeo

* Onde encontrar a ID do fluxo de dados na Adobe Experience Platform em Coleção de dados > Fluxos de dados
* Como adicionar a configuração do fluxo de dados e copiar o script de instalação resultante
* Instalação de componente em comparação às opções de instalação de página inteira do script
* Como configurar regras de superfície correspondendo domínios e caminhos (qualquer, começa com, termina com, é igual a)
